**README** - YOLO Person Detector

*By Manuel Heredia*



**About the program**

YOLO Person Detector is a Python program made by Manuel Heredia that uses YOLO object detection models to identify people in images. It can analyse individual images or entire folders, count detected people, and save annotated images with bounding boxes around each detection.



Follow this guide to set up and launch the program for the first time.



1\.	**Install Python if you do not already have it installed**

Download and install Python from the official website:

https://www.python.org/downloads/

The installation may take some time, depending on your internet connection. This is normal.



2\.	**Install the required libraries**

Open a terminal and navigate to the folder containing the programme.

Run the following command to install the required libraries:

pip install -r requirements.txt

The installation may take some time, depending on your internet connection. This is normal.



3\.	**Run the program**

In the same terminal, run this command if you are on a Windows system:

py YOLO\_person\_detector.py

And this one if you are on another operating system:

python YOLO\_person\_detector.py



4\.	**Read the in-program instructions (optional)**

If this is your first time using the program, when it starts and shows the main menu, select '2. Read the instructions' to understand how it works. This will explain how to select a model, choose a confidence threshold, select images, run detections, and view the results. Also read through the warnings that appear upon selecting the same menu option.
